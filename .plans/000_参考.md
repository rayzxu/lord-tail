# Plan 01: Port body_parts from CDDA

## 目标
把 CDDA 的 `data/json/body_parts.json` 中**每个 `type: "body_part"` 的对象**，逐一翻译为本项目格式，写入：

```
/Users/ray/raylab/era-rpg/backend/data/body_parts/<id>.json
```

每个部位一个文件，文件名 = 该部位的 `id`（如 `torso.json`、`arm_l.json`）。

## 输入

- 源：`/Users/ray/raylab/Cataclysm-DDA/data/json/body_parts.json`
- 参考：`/Users/ray/raylab/era-rpg/cataclysm_doc/anatomy_bodypart_injury.md`（保留对照）

## 输出 schema（严格遵守）

```json
{
  "id": "torso",
  "name": "torso",
  "main_part": "torso",
  "side": "both",
  "is_vital": true,
  "is_limb": false,
  "base_hp": 60,
  "hit_size": 36.0,
  "hit_difficulty": 1.0,
  "encumbrance_threshold": 6,
  "encumbrance_limit": null,
  "drench_capacity": 4000,
  "connected_to": "head",
  "opposite_part": "torso",
  "effects_on_hit": [
    {
      "id": "bleed",
      "dmg_type": "cut",
      "dmg_threshold": 3,
      "dmg_scale_increment": 2,
      "duration": 60,
      "duration_dmg_scaling": 45,
      "max_duration": 1800,
      "chance": null,
      "chance_dmg_scaling": null,
      "intensity": null,
      "intensity_dmg_scaling": null,
      "max_intensity": null
    }
  ]
}
```

### 字段映射规则

| era-rpg 字段 | CDDA 来源 | 处理 |
|---|---|---|
| `id` | `id` | 原样 |
| `name` | `name`（如果是 `{"str": "..."}` 取 `str`） | 字符串 |
| `main_part` | `main_part` | 缺失时 = `id` |
| `side` | `side` | 取值 `"left"`/`"right"`/`"both"`；缺失 = `"both"` |
| `is_vital` | `is_vital` | 缺失 = `false` |
| `is_limb` | `is_limb` | 缺失 = `false` |
| `base_hp` | `base_hp` | 缺失 = `0` |
| `hit_size` | `hit_size` | 转 float；缺失 = `0.0` |
| `hit_difficulty` | `hit_difficulty` | 转 float；缺失 = `1.0` |
| `encumbrance_threshold` | `encumbrance_threshold` | 缺失 = `null` |
| `encumbrance_limit` | `encumbrance_limit` | 缺失 = `null` |
| `drench_capacity` | `drench_capacity` | 缺失 = `null` |
| `connected_to` | `connected_to` | 缺失 = `null` |
| `opposite_part` | `opposite_part` | 缺失 = `null` |
| `effects_on_hit` | `effects_on_hit` | 数组，每条 5 个必填字段（id/dmg_type/dmg_threshold/dmg_scale_increment/duration），其余 `null` |

### 不要做的事
- **不要**翻译/改 `id` 大小写。
- **不要**合并 `name` 的多语言条目；只保留英文 `str`。
- **不要**保留 CDDA 中其它字段（`limb_types`、`limb_scores`、`bionic_slots`、`bmi_*`、`techniques` 等）—— MVP 用不到，丢弃。
- **不要**自己造效果 id，原文有什么就写什么。

## 步骤

1. 读取源文件，找出所有 `"type": "body_part"` 顶层对象。
2. 对每个对象，按上表映射，写入 `backend/data/body_parts/<id>.json`，**单文件，UTF-8，缩进 2 格**。
3. 写完一个就跑：
   ```bash
   python3 -c "import json; json.load(open('/Users/ray/raylab/era-rpg/backend/data/body_parts/<id>.json'))"
   ```
   非零退出即失败，必须修复。
4. 全部写完后，运行验证脚本（见下）。

## 验证

```bash
cd /Users/ray/raylab/era-rpg
python3 - <<'PY'
import json, pathlib, sys
required = {"id","name","main_part","side","is_vital","is_limb","base_hp","hit_size","hit_difficulty"}
ok = True
for p in pathlib.Path("backend/data/body_parts").glob("*.json"):
    d = json.loads(p.read_text())
    missing = required - d.keys()
    if missing:
        print(f"FAIL {p.name}: missing {missing}"); ok = False
    if d["id"] != p.stem:
        print(f"FAIL {p.name}: id mismatch ({d['id']} vs {p.stem})"); ok = False
print("OK" if ok else "FAIL"); sys.exit(0 if ok else 1)
PY
```

最少应有这 12 个文件（CDDA 人形）：
`head, eyes, mouth, torso, arm_l, arm_r, hand_l, hand_r, leg_l, leg_r, foot_l, foot_r`。
